A structured, research-grade Python codebase for solving open-pit mine scheduling problems using the [MineLib benchmark library](https://mansci-web.uai.cl/minelib/).

**What it includes.**
- Clean problem formulations for MineLib-format instances (precedence, capacity, NPV objective)
- Multiple solver implementations with a unified interface
- Benchmarking harness and results tracking
- Reproducible experiment structure (black-formatted, MIT-licensed)

**Role.** Shared infrastructure underpinning the RL and ML mine-scheduling projects above.

**Stack.** Python, Pyomo, Gurobi.
